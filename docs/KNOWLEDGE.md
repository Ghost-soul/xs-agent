# 知识检索与升级

知识索引按作品、正式版本和候选阶段绑定，正文与正式资料仍是权威来源。索引可重建，废弃版本不会混入当前写作资料；新角色输入在预算内选择必要状态、连续性与历史证据。无需把小说数据写入镜像。

本次迁移 head 为 `20260925_0048`，增加知识索引表和 pgvector 扩展。服务器升级前备份数据库及应用数据卷，并确认没有在途创作。使用仓库的 `docker-compose.yml` 启动时会运行迁移；本地源码更新不会自动迁移其他实例。

镜像安装 ONNX Runtime 和 NumPy 的 CPU 依赖，模型权重单独保存在持久目录。没有可用模型时使用精确／词法检索；不会在写作请求中自动下载模型。模型安装命令和参数可通过容器中的 `python -m novel_writer.knowledge.install_model --help` 查看。更换模型应重建对应索引，不混用不同模型的向量。

安装默认模型的命令为 `docker compose exec app python -m novel_writer.knowledge.install_model --destination /app/data/models/knowledge`；这只下载公开模型权重，不上传小说。安装后在作品资料的「本书知识库与检索」查看状态，需要时点击「重建本书索引」。

界面显示「语义索引已就绪」时可使用语义检索，否则仍可使用文本检索。检索提供参考证据，不能将未来计划当作事实，也不等同于模型文学效果验收。
